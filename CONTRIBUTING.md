# Contributing

For substantive changes, preserve an Issue → PR → tests/evidence → merge trail. State the artifact/trace proposition or defect, affected authority and compatibility boundary, and acceptance criteria; implement the smallest coherent change; add deterministic positive/negative validation where consequential; and merge only after applicable checks pass.

Do not silently broaden the authority of these artifacts beyond their declared scope, and do not treat missing, stale or incompatible trace evidence as PASS.

Security reports must follow [`SECURITY.md`](SECURITY.md).
