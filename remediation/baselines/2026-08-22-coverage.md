# First remediation coverage baseline

Source: the DPI AI Governance Lab's August 2026 rebaseline of three existing substantive TRACE reviews.

## Coverage signal

| Measure | Result |
| --- | ---: |
| Publications rebaselined | 3 |
| Material gaps encoded | 9 |
| Recurring capability clusters | 3 |
| Standardized remediation mappings | 6 |
| Partial remediation mappings | 3 |
| Unmapped gaps | 0 |
| Evidence-backed closed gaps | 0 |

## Capability recurrence

| Capability | Reviews | Coverage | Product implication |
| --- | ---: | --- | --- |
| `CAP-AUTHORITY-BOUNDED-DELEGATION` | 3/3 | Partial | highest-priority remediation-development gap |
| `CAP-REDRESS-APPEAL` | 3/3 | Standardized | instantiate and test; do not add templates without evidence of need |
| `CAP-EVIDENCE-CLOSURE` | 3/3 | Standardized | instantiate evidence bundle and verify closure |

## Interpretation

The baseline is useful because it distinguishes **artifact availability** from **governance closure**. All nine gaps have at least a partial artifact mapping, but none is closed because publication-level reviews cannot supply deployment implementation evidence.

The repository should therefore prioritize strengthening the repeatedly observed partial authority/delegation capability, while using realistic deployment fixtures to test whether the standardized redress and evidence assets are actually sufficient.

## Provenance boundary

This baseline imports the Lab's normalized capability signal. The Lab retains evaluation provenance; this repository owns only its reusable remediation mapping and artifact-development decisions.
