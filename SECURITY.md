# Security Policy

Security and governance-artifact integrity fixes are applied to current `main` and the latest supported release identified by repository status/version metadata. Older versions should be treated as unsupported unless a maintainer explicitly states otherwise.

Do not disclose undisclosed vulnerabilities in public issues. Use GitHub private vulnerability reporting when available, or contact the repository maintainer through a private channel identified on the maintainer profile.

Include the affected artifact/version/revision, reproduction steps, impact, affected evidence/trace surfaces, and any known mitigation.

This repository publishes governance artifacts and machine-readable traces, not external regulatory or certification decisions. A defect that can change artifact semantics, trace compatibility, provenance, authority boundaries, or downstream evidence must identify affected artifacts and must not silently preserve stale or invalid evidence as PASS.
